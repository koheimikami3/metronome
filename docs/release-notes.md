# リリースノート

App Store の「このバージョンの新機能」に掲載した文面を、そのまま記録する。
**提出のたびにここへ追記すること。** ストア側の文面は後から遡って読むのが手間なため、
リポジトリ内に控えを持つ。

書き方の決まり:

- 「〜しました。」の短い行を並べる。1 行 1 項目で、2〜4 行に収める
- **内部の仕組みには触れない**。クラス名・API 名は書かず、利用者から見て何が
  変わったかだけを書く
- 半角英数の前後には空白を入れる(`iPhone 版`、`120 BPM`)
- **初版にはリリースノートを書けない**(App Store Connect に入力欄が無い)。
  1.0.0 が該当し、空欄が正しい
- **見出しの build 表記が使用済みビルド番号の台帳を兼ねる**。番号は全履歴を通じて
  単調増加で再利用しない。リジェクトで捨てた番号や、自動で繰り上がった番号も必ず書く。
  次に使うのは最大値 + 1

## 1.0.0 (build 5)

初版。リリースノートの入力欄が無いため空。

build 1〜3 は提出後に **ITMS-91056(プライバシーマニフェストが不正)**で
差し戻されたため欠番(番号は再利用できない)。

- build 1 — `PrivacyInfo.xcprivacy` に XML コメントを入れていた
- build 2 — コメントを外したが同じエラー。**コメントは原因ではなかった**
- build 3 — destination を Any iOS Device にして取り直したが同じエラー。
  アーカイブは 1 / 2 とも `iPhoneOS` / arm64 で正しく、**これも原因ではなかった**
- build 4 — **`PrivacyInfo.xcprivacy` 自体を削除**。無くても提出は通る
  (`UserDefaults` について ITMS-91053 の警告メールが届くが、提出は止まらない)
- build 5 — build 4 は提出せず、実機テストで見つかった不具合を入れて差し替えた。
  背面から戻ると**拍だけ進んで無音**になる件(プレイヤーの張り直し漏れ)と、
  音色 5 種(メトロ1 / ウッド / カウベル / リム / デジタル)の作り直し
