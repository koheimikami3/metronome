## 全体

- iPhone 縦向き専用。ライトモード固定(ダークモードは対象外)
- 3 タブ構成: メトロノーム / 拍子 / 設定
- 再生中はバックグラウンドでも鳴り続ける(ホームに戻る・画面ロック・他アプリ使用中)
- 再生中は画面を自動で消灯させない
- 他アプリの音楽と重ねて鳴らせる(音楽を止めない)
- 電話などの割り込みが終わったら、鳴っていた状態に自分で戻る
- 設定はアプリを閉じても保持する(テンポ・拍子・分割・強弱・音色・テーマ・音量)

## 01 メトロノーム画面

- **テンポ表示** — 現在の BPM を大きく表示。下に `BPM`、右上にテンポ用語
  (Largo / Adagio / Andante / Moderato / Allegro / Presto)
- **テンポ操作**
  - `−` / `＋` で 1 ずつ増減
  - スライダーでドラッグ(40–240 BPM)
  - BPM 表示のタップで数値を直接入力(30–280 BPM)
  - プリセット 60 / 80 / 100 / 120 / 140 をタップで即設定。現在値と一致する 1 つが選択表示
  - 指定できる範囲は全体で 30–280 BPM
- **TAP** — 連打した間隔の平均からテンポを決める。直近 2.4 秒より古いタップは捨てる。
  タップのたびにクリック音が 1 回鳴る
- **START / STOP** — 再生のオン・オフ。再生中はボタンの見た目が変わる
- **振り子** — 再生中、1 拍ごとに左右へ振れる。停止すると中央に戻る
- **拍ドット** — 1 小節の拍数ぶん並び、鳴っている拍が点灯する。
  強拍は大きく、休符に設定した拍は薄いまま点灯しない
- ヘッダーに現在の拍子と分割を表示(例 `4/4 ・ 8分`)

## 02 拍子画面

- **分子(拍数)** — 分母ごとに選べる値が変わる
  - 4 分: 2 / 3 / 4 / 5 / 6
  - 8 分: 3 / 5 / 6 / 7 / 9 / 12
  - 16 分: 5 / 7 / 9 / 12
  - 分母を変えたとき、今の分子が選べない値なら先頭の値に寄せる
  - 見出しは分母で変わる(「1小節の拍数」/「1小節の8分音符数」/「1小節の16分音符数」)
- **分母(1拍の音符)** — 4分 / 8分 / 16分
- **複合拍子の自動判定** — 分母が 8 か 16 で、分子が 3 の倍数かつ 6 以上のときは
  3 つずつをまとめて 1 拍として数える。見出しの右に「N 拍 / 小節(3つずつ)」と出す。
  **単純拍子では出さない**(分子チップと見出しがすでに言っていることの繰り返しになるため)
- **強弱** — 拍ごとに棒が並び、タップで 強 → 弱 → 休 → 強 … と巡回する。
  棒の高さと色が段階で変わり、下に「強」「弱」「休」を表示。
  タップした拍の音がその場で 1 回鳴る(休は鳴らさない)
  - 「リセット」で 1 拍目だけ強・残りを弱に戻す
  - 拍数が変わったら、足りない分は弱で埋め、はみ出た分は捨てる
  - 再生中は鳴っている拍の棒に印が出る
- **分割** — 1 拍を何個に割るか。音符の絵で選ぶ。分母と複合拍子かどうかで選択肢が変わる
  - 4 分: 4分 / 8分 / 3連 / 16分
  - 8 分(単純): 8分 / 16分 / 3連
  - 8 分(複合): 付点4分 / 8分 / 16分
  - 16 分(単純): 16分 / 32分
  - 16 分(複合): 付点8分 / 16分
  - 分母を変えたら分割は先頭に戻す
  - 拍の頭以外(分割で増えた音)は弱い音で鳴らす
- 右上に現在の拍子(`4/4` など)を表示

## 03 設定画面

上から順に。この画面だけ縦スクロールする。参照実装には無かった画面タイトル「設定」と
「クリック音」の見出しを足している(他の 2 画面にタイトルがあり、揃えたほうが読みやすいため)。

- **Pro(広告を非表示にする)** — **初版では出さない**。押しても何も起きないカードを
  置くより無いほうがよい([design.md](design.md) 参照)。課金を入れるときに戻す
- **クリック音** — 6 種から 1 つ選ぶ。ウッド / クリック / ビープ / メトロ / リム / カウベル。
  選んだ瞬間にその音が鳴る
- **テーマ** — 10 色から 1 つ選ぶ。トープ / キャラメル / ソフトアプリコット /
  セージグリーン / ダスティティール / ダスティブルー / ペリウィンクル /
  ブリックレッド / ダスティローズ / チャコール。
  選ぶと画面全体の配色が切り替わり、下に選択中のテーマ名を表示
- **音量** — スライダーでクリック音の音量を変える
- **サポート**
  - 「App Store でレビューを書く」— App Store のレビュー投稿画面を開く。
    **App ID 未設定のあいだはセクションごと出さない**
- **作者の他のアプリ** — アイコン・アプリ名・ひとこと説明・「入手」ボタン
  - サブリス(サブスクと固定費をリストで管理)
  - シンプル英単語帳(自分で作る暗記カード)
- **情報**
  - バージョン(表示のみ)
  - ライセンス — タップでライセンス一覧を開く
